Comment utiliser ce support

Stratégie de révision en 4 passes

  1. Passe 1 — lecture active (1 matière par jour) : lisez le cours en entier, chapitre par chapitre. Ne surlignez pas : reformulez à voix haute chaque encadré « piège d'examen ».
  2. Passe 2 — QCM par chapitre : ouvrez l’onglet QCM, filtrez sur un chapitre, niveau « Tous ». Une question à la fois, correction expliquée immédiatement. Objectif : comprendre les explications, pas le score.
  3. Passe 3 — rejeu des erreurs : le bouton « Rejouer mes erreurs » reconstitue une série ciblée à partir de vos ratés mémorisés. Répétez jusqu'à liste vide.
  4. Passe 4 — simulation : 60 questions tirées de tous les chapitres. Visez 85 % avant de considérer la matière acquise.

Repères pour chaque épreuve

  • INF5243 / INF5244 — examen Moodle sans documents ni Internet + travail de synthèse sur environnement virtualisé. Travaillez la précision : ports, sigles, noms exacts des fonctions de sécurité, syntaxe nftables.
  • ENT5003 — examen écrit + projet d'équipe. Travaillez le raisonnement : plan de réponse, vocabulaire exact (valeur métier vs bien support, qualification vs homologation), chiffres réglementaires.
  • Les trois matières se recoupent : la DMZ, le WAF, le proxy, la journalisation et le Zero Trust apparaissent dans plusieurs cours. Réviser l'une consolide les autres.

Fonctions des pages

  • Ctrl + K : recherche dans tous les chapitres, y compris ceux qui ne sont pas affichés ; un clic ouvre le bon onglet et surligne le passage.
  • Navigation par onglets : un chapitre à la fois, progression de lecture et boutons Précédent / Suivant.
  • Bouton ◐ : thème clair / sombre · bouton ⎙ : impression ou export PDF propre.
  • Le QCM mémorise vos statistiques dans le navigateur (aucune donnée n'est envoyée nulle part).

Avertissement
Ce support a été rédigé à partir des syllabus officiels des trois matières et de l'état de l'art public (référentiels ANSSI, NIST, ISO, OWASP). Il couvre largement le programme annoncé, mais il ne remplace pas les supports de vos enseignants : les cotations, échelles et exemples utilisés en TD peuvent différer. Vérifiez en particulier les dates de textes réglementaires récents et les conventions de notation propres au cours.
